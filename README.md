# סידור עבודה

אפליקציית סידור משמרות (א׳ · ב׳ · ג׳): לוח חודשי ושנתי, טיוטת השנה הבאה עם מנוע הוגנות, וצ׳אט תיקונים.

- הגרסה המלאה (מנהל): https://wwvdng29r6-ctrl.github.io/Sidur/
- גרסת המפקדים: https://wwvdng29r6-ctrl.github.io/Sidur/mefakdim/ — צפייה בסידור הרשמי והמאושר, אימונים משותפים ופתקים. נכנסים עם קוד הצטרפות מהמנהל.

## מבנה

- `src/sidur.src.html` — קובץ המקור של שתי הגרסאות. קטעים מסומנים ב־`@admin` / `@member` שייכים לגרסה אחת בלבד.
- `src/build.py` — בונה את `index.html` (מנהל) ואת `mefakdim/index.html` (מפקדים) מקובץ המקור.

הנתונים של הגרסה המלאה נשמרים בדפדפן ומסתנכרנים בין המכשירים שלך דרך Firebase (קוד סנכרון). גרסת המפקדים מקבלת מהענן רק את מה שהמנהל פרסם, ושומרת את הפתקים בטלפון ובענן — מוצפנים.
